# 🥷 Ninja Force

Application Web (PWA) de fitness conçue pour des séances fluides et fiables, sans friction.

## Fonctionnalités
- Création et modification de routines personnalisées.
- Moteur d'entraînement robuste basé sur une Machine d'État.
- Décompte de préparation, minuteur d'exercices et gestion stricte des pauses.
- Utilisation de l'API Web Audio pour garantir le fonctionnement sonore sur iOS.
- Wake Lock API pour empêcher la mise en veille pendant l'effort.
- Utilisation locale et hors-ligne (PWA / LocalStorage).

## Déploiement
Compatible avec GitHub Pages. Le projet est entièrement front-end (HTML, CSS, JS Vanilla).
Aucune compilation n'est requise.
