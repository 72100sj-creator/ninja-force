# 🥷 NINJA FORCE (v1.1)

**NINJA FORCE** est une application web progressive (PWA) d'entraînement au poids du corps, conçue pour être simple, rapide, stable et utilisable hors-ligne.

## ✨ Nouveautés de la version 1.1
- **Séances sur mesure :** Crée, nomme et sauvegarde plusieurs compositions de séances personnalisées.
- **Gestion des tours :** Choisis librement le nombre de tours que tu souhaites effectuer pour chaque séance.
- **Sélection des exercices :** Coche ou décoche les exercices de ton choix depuis la bibliothèque complète.
- **Confort visuel :** Fiches d'exercices agrandies, interface sombre optimisée et correction des boutons pour s'adapter parfaitement à tous les écrans mobiles.

## 🚀 Utilisation
L'application fonctionne directement dans ton navigateur et peut être installée sur ton téléphone. Elle est hébergée et mise à jour via **GitHub Pages**.
